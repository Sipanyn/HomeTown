# 🏡 My Hometown — Urmia

A simple and responsive hometown website built with **HTML5 and CSS3** to introduce **Urmia**, its atmosphere, places to visit, and the personal connection I have with the city.

The project focuses on practicing fundamental frontend development concepts such as semantic HTML, CSS layouts, responsive design, navigation, typography, and image-based visual design.

## 📖 About The Project

**My Hometown** is a single-page website dedicated to Urmia.

The page introduces the city through a visual landing section and provides information about what makes the hometown special. Visitors can explore different sections of the page using the navigation menu.

The website includes:

- A full-screen hero section
- Navigation menu
- Introduction to Urmia
- Places to visit
- Image cards
- Inspirational quote section
- Footer/contact section
- Responsive mobile layout

The content and layout are implemented as a static frontend without a backend or external JavaScript framework.

---

## ✨ Features

### 🏙️ Hero Section

A full-screen hero section introduces Urmia with:

- Background city image
- Dark overlay
- Navigation
- Main heading
- Short introduction
- "Discover More" call-to-action

The hero uses `city-hero.jpg` as its background image.

### 📍 About The City

The About section provides a short personal introduction to the city alongside a hometown image.

### 🗺️ Places To Visit

The website displays three featured places:

- **City Park** — A peaceful place to walk and relax
- **Local Market** — A place to experience local food and culture
- **Mountain View** — A scenic area with beautiful views

Each location is presented as a visual card containing an image, title, and description.

### 💬 Quote Section

A dedicated section displays a quote about the meaning of home and memories.

### 📱 Responsive Design

The layout adapts to smaller screens.

On screens below `768px`:

- Navigation links are hidden
- The About section changes from two columns to one
- Place cards change from three columns to one
- Heading sizes are reduced

This behavior is implemented using CSS media queries.

## 🚀 Getting Started

Since this is a static HTML/CSS project, no package manager or build tool is required.

### 1. Clone the repository

```bash
git clone https://github.com/Sipanyn/HomeTown.git
```

### 2. Enter the project directory

```bash
cd HomeTown
```

### 3. Open the project

Open `index.html` directly in your browser.

Alternatively, you can use **VS Code Live Server** for local development.

## 🎨 Design

The website uses a clean, image-focused design with:

- Full-screen hero imagery
- Centered typography
- CSS Grid layouts
- Rounded image corners
- Card-based content
- Smooth scrolling
- Simple hover effects
- Responsive breakpoints

The desktop layout uses a two-column About section and a three-column Places section, while the mobile layout switches these sections to single-column layouts.
